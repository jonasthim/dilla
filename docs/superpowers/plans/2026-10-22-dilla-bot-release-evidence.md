# Dilla Bot release evidence — 22 October 2026

This is an implementation checkpoint for `feat/dilla-bot`, not a release sign-off. The complete-release gate in [the plan](2026-10-21-dilla-bot.md) remains in force. The bot is a separate Linux service on the same host as `dillad`; Spotify authorization belongs in Dilla server settings. Librespot is the selected Spotify playback backend.

## Open release blockers

1. **Encrypted interactions:** kind-3 Bot interaction groups remain refused by the Go dispatcher. Signed issuance, credential-backed roster extraction and isolated Rust/Go roster checks exist, but Rust load, Welcome, registration and the server must bind them to one current authenticated group, pinned trust context and durable receipt end to end. Consequently the settings/command control plane is not fully reachable.
2. **Production music path:** `cmd/dillabot` reconciles identities and performs welcome/announcement passes and retains paused supervisors, but does not own persistent interaction dispatch or call the queue snapshot bridge after authorized music mutations. Live local YouTube extraction/Opus passes, while intended-host playback, packaging and browser decryption remain unqualified. Spotify PCM has no live account qualification.
3. **Spotify qualification:** the local pinned librespot probe builds as version 0.8.0 and synthetic PCM through FFmpeg passes. The dependency doctor sees yt-dlp 2026.8.19, FFmpeg/ffprobe 9.0.2, and Node 24.15.0, but reports provider qualification unverified. No dedicated Premium account was connected (`DILLA_PROBE_STATE` is unset); actual librespot audio, playlist expansion, playback controls, and encrypted browser playback on the intended host remain unverified. The qualification gate cannot be inferred from passing unit tests.
4. **Community and moderation integration:** zero-capability installation readiness and the Roles-enabled join/leave/rejoin path pass in a real Chromium browser. A complete music panel, authoritative moderation evidence attachment and retrieval, and whole-release browser scenarios remain open. Full backup/restore acceptance has not been run.

No live deployment or release has been performed.

# dilla v0.1.0-noise-beta.5

## What's new

- The release and CI workflows use only commit-pinned GitHub Actions. The Rust, Go lint, and sqlc tools come from versioned publisher archives verified against checked-in SHA-256 hashes before execution.
- The CI image still builds for linux/amd64 and linux/arm64, with provenance and an SBOM, using a digest-pinned BuildKit daemon.
- The deployment guide now diagrams how an open browser tab detects a new web build, reloads, restores its encrypted checkpoint, and rejoins community voice.
- Community managers can choose an existing voice channel as a silent AFK destination and set a 1, 5, 15, 30 or 60 minute inactivity timeout. The server moves each idle device out of its media room, and the desktop and phone voice lists show who is AFK. Members can move there manually and return by joining another voice channel.

## Operator notes

- The `00020_afk` migration raises the server schema from 19 to 20. Back up and verify the database before upgrading. Client store schema remains 5; message and encryption formats are unchanged.
- AFK activity is per device: keyboard, pointer, touch and microphone speech reset the timer. Quiet listening and activity on another device do not. AFK has no microphone, camera, screen share or incoming call audio.
- When upgrading directly from beta.3 or earlier, follow the beta.4 notes for the first `in_process` to sidecar migration and ask members to reload tabs loaded before beta.4 once.

# v0.1.0-bot1.3

Bot recovery after an installation is disabled and re-enabled while joining:

- Read the current installation revision after replaying the durable credential receipt, so Ready uses the current revision.
- Retry text-group reconciliation when the server reports that a locally held group no longer includes the Bot.
- Ask the delivery service to propose missing Bot memberships when Ready finds eligible encrypted text channels without the Bot's current leaf.
- Accept a cryptographically verified Bot re-admission Welcome for the same group binding only after at least two newer MLS epochs; older Welcome replays remain refused.

The Bot stays pending until a current group member commits the proposed Add and the Bot consumes its new Welcome.

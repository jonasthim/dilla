# dilla v0.1.0-web3.7.2

## What's new

- **On an iPhone the screen sits flush on the keyboard.** With the keyboard open there is no empty band between the
  screen and the keyboard, and the channel header stays on screen instead of scrolling off the top. The incoming-call
  ring, Settings and search follow the same position.
- **A muted mic in the phone call bar reads as off.** The mute button now shows a red glyph and edge, as on desktop,
  not a green fill.

## Operator notes

- No database migration: the server schema stays at 18.
- No browser store change: the client store stays at schema 5, so nothing changes in any browser's data.
- The browser wasm core is unchanged: it is the same `dilla_core_wasm_bg-<hash>.wasm` file as web3.7, so the name
  proves it.
- Rolling back to web3.7.1 is safe.
- Ask users to reload open tabs to get the change.
- No configuration changes.

# dilla v0.1.0-noise-beta.1

This prerelease adds **Automatic (beta)** noise suppression in **Settings → Voice**. Lightweight remains the default. Existing Off and Lightweight choices are preserved; enhanced processing starts only after an explicit Automatic selection.

- DeepFilterNet3 runs locally before encryption. Model and WASM assets are pinned and served from dilla's origin; microphone audio is not uploaded for enhancement.
- Processing falls back to RNNoise, then browser suppression if needed, with the effective mode and reason visible.
- The local microphone test records at most ten seconds in memory, stops capture before playback, and discards the recording when closed. It is unavailable during calls.
- Mute and push-to-talk remain independent of enhancement. Screen-share audio keeps its existing path.

## Known limitations

This is a risk-accepted opt-in beta, not a qualified quality release. No Krisp parity is claimed. Prior Linux Chromium short tests measured 58–76 ms added delay, but the 60 ms target was not consistently met. A loaded 30-minute test fell back to RNNoise near minute 26, and short stress tests also lost buffers. Glitches, extra delay and fallback remain possible.

Physical Safari, iOS and Android coverage and the matched blind listening study are incomplete. Linux Playwright WebKit produced no audio in evaluation; that is not a Safari pass.

DeepFilterNet code carries MIT/Apache-2.0 notices. The exact pretrained-weights redistribution grant remains ambiguous, and upstream issue [#712](https://github.com/Rikorose/DeepFilterNet/issues/712) is unresolved. Publication was explicitly authorized by the project owner after disclosure; this release does not claim that upstream supplied additional license clearance. The source repository retains the artifact audit, failed results and qualification gates.

## Operator notes

- Install this exact prerelease tag. The release workflow selects the beta build only for `vX.Y.Z-noise-beta.N` tags; ordinary release tags continue to exclude enhancement assets.
- Ask users to reload their tabs, then choose **Automatic (beta)** if they want to try it.
- To leave the beta immediately, select **Lightweight**. To remove the option deployment-wide, reinstall `v0.1.0-web3.7.2` or build the ordinary profile.
- No server API, encryption protocol, database schema or browser-store schema change is introduced by this feature.

# dilla v0.1.0-web3.7.1

## What's new

- **The bottom tabs stay on every phone screen.** The tabs (Servers, DMs, Activity, You) are now under a channel, a
  direct message, the call stage and the sheets (members, threads, pins). They step aside only while you type, so the
  message box sits right above the keyboard, and they come back when you leave the field.
- **Settings on a phone is a page under the tabs.** Settings and a server's settings no longer cover the whole screen.
  Back, Escape or a tab leaves them.
- **Tapping the current tab returns to its list.** In a channel, tapping Servers shows the channel list. Tapping another
  tab still opens it where you left it. Tapping a tab while a sheet is open closes the sheet and opens the tab.

## Operator notes

- No database migration: the server schema stays at 18.
- No browser store change: the client store stays at schema 5, so nothing changes in any browser's data.
- Rolling back to web3.7 is safe.
- Ask users to reload open tabs to get the change.
- No configuration changes.

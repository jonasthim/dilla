# Artifact licensing audit (2026-10-17)

The exact files and source revisions are in `../asset-lock.json`. Build-time acquisition is explicit in `../prepare.mjs`; no upstream assets are requested at runtime. The evaluated DeepFilter runtime is pinned in `third_party/noise/` for beta release builds. Other model/WASM files and the native Hush binary remain ignored development artifacts; ordinary application builds exclude enhancement assets. Qualified builds require separate model licensing evidence.

On 2026-10-17 the owner explicitly instructed release after this audit's uncertainty was disclosed. The opt-in beta publication proceeds under that authorization and retains the root MIT/Apache-2.0 notices. This records the release decision, not a new upstream license grant or a cleared exact-weights audit. Qualified release/default migration still requires that separate evidence.

Build notes: DeepFilterNet's resolved Cargo lock is committed separately because wasm-pack metadata resolution updates the old upstream lock before invoking Cargo. The small `deepfilter-free.patch` adds the correct destructor for `df_create`'s raw Box; wasm-bindgen's class destructor has a different pointer contract. The patch also resets recurrent/session state, FFT overlap and normalization history without rebuilding compiled inference plans; a deterministic reset test compares output with a fresh model. All inference still uses upstream weights and settings. Native Hush uses the pinned upstream binary; its timings must not be reported as browser measurements. Renaming the gzip model to `.bin` prevents dev servers from transparently decompressing it through `Content-Encoding: gzip`, which would break both its hash and the native loader's expected bytes.

The author's [DeepFilterNet3 paper](https://arxiv.org/abs/2305.08227) states that the framework and pretrained weights are published under an open-source license. That supports open-source intent but does not itself disambiguate the exact grant for this archive. The corresponding [upstream checkpoint-license question #712](https://github.com/Rikorose/DeepFilterNet/issues/712) remained open when inspected on 2026-10-17. Production qualification therefore still requires exact license evidence.

The speech corpus comes from [Google FLEURS](https://huggingface.co/datasets/google/fleurs), whose dataset card declares CC-BY-4.0. The acquisition manifest retains Google/Conneau et al. attribution, dataset source hashes, source IDs and modifications. Audio and converted parquet files are ignored local artifacts; the repository includes metadata and result hashes only.

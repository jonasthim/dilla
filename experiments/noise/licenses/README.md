Build notes: DeepFilterNet's resolved Cargo lock is committed separately because wasm-pack metadata resolution updates the old upstream lock before invoking Cargo. The small `deepfilter-free.patch` adds the correct destructor for `df_create`'s raw Box; wasm-bindgen's class destructor has a different pointer contract. All inference still uses upstream weights and settings. Native Hush uses the pinned upstream binary; its timings must not be reported as browser measurements. Renaming the gzip model to `.bin` prevents dev servers from transparently decompressing it through `Content-Encoding: gzip`, which would break both its hash and the native loader's expected bytes.
